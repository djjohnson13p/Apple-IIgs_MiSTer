# Custom Diagnostic Tests

Bootable 65816 test disks for exercising the core's subsystems. Each test prints a
PASS/FAIL verdict on screen, so it can be checked from a `--screenshot` in vsim.

## Building

```bash
make                # build all 21 test disks
make mmu_test       # build just one
make clean          # remove built .SYSTEM files and disk images
```

Merlin32 (assembler) and CiderPress2 (disk imager) are downloaded automatically on
first build — they are not committed to the repository. `make download-tools`
fetches them without building.

- **Merlin32** v1.2 beta 2 — https://brutaldeluxe.fr/products/crossdevtools/merlin/
- **CiderPress2** v1.1.1 — https://github.com/fadden/CiderPress2

`blank.2mg` is the bootable ProDOS template that every test disk is built from.

## Running

Boot a test disk in the simulator and screenshot the frame where it settles:

```bash
cd ../vsim
./obj_dir/Vemu --disk ../customtests/mmu_test.2mg --stop-at-frame 130 --screenshot 130
```

`mmu_test` is wired into `vsim/regression.sh`; the rest are run by hand.

## The tests

| Test | Covers |
|------|--------|
| `mmu_test` | MMU / shadowing / language-card decode. **Used by regression.sh.** |
| `gsqmmu_test` | Shadowing, RAMWRT and aux-bank cases ported from the GSquared emulator's MMU suite — an independent cross-check of `mmu_test`. |
| `selftest01`–`selftest0c` | Jump straight to one ROM selftest (01=ROM, 02=RAM, … 0c=Ensoniq sound) instead of sitting through the full run. |
| `scc_selftest` | SCC register-level replica of ROM selftest 06-01. |
| `scc_crosschan` | SCC A-TX→B-RX and B-TX→A-RX through the real UART serializers (not internal loopback). |
| `scc_both` | 3-deep RX FIFO on both SCC channels. |
| `adb_device_enum` | ADB GLU FLUSH/TALK handshake against an absent device. |
| `adb_rom_checksum` | ADB microcontroller ROM checksum. **Pinned to the ROM3 ADB µC ROM — expect a failure under ROM1.** |
| `floppy_rw_test` | Block-level write/read/verify against 5.25" and 3.5" WOZ media (generated by `cp2`). |
| `time` | ProDOS `GET_TIME` smoke check for the RTC clock driver. |

## History

This directory previously held ~35 additional tests: one-off probes written during
the SCC read-timing, DBR/PLB-corruption and Y-register-race bug hunts. Those bugs
are fixed (see `SCC_SERIAL_TEST_ANALYSIS.md`) and the probes were dropped — most
had no PASS/FAIL verdict, several encoded hypotheses that turned out to be wrong,
and a few could not terminate.
